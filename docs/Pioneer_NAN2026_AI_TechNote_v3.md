# Pioneer NAN 2026 AI 활용 기술문서
**작성일:** 2026-08-08 | **버전:** v1.8.1 | **실행파일:** `Pioneer_v1.8.1_portable.exe`

---

## 요약

Pioneer의 AI 활용은 두 축입니다.

1. **게임 내부 AI형 시스템:** 3분 소폭 가격 변동, 1시간 대형 시장 사건, 플레이어 거래 영향, 가격 히스토리를 결합해 반복 플레이의 예측 불확실성을 만듭니다.
2. **개발 과정 AI 보조:** 기획 검토, 로직 분리, 테스트 케이스 설계, 문서 초안/정리, 이미지 방향성 검토에 생성형 AI를 사용했습니다.

## 게임 내부 동적 시장 모델

```text
3분 소폭 변동
  모든 항구와 상품의 기준가에 작은 노이즈를 적용

플레이어 거래 영향
  매입/판매 수량에 따라 해당 항구의 해당 상품 가격을 즉시 조정

1시간 대형 시장 사건
  플레이어 거래 맥락과 독립적으로 2~4개 항구에 큰 가격 충격 적용
```

| 시스템 | 주기 | 목적 |
|---|---:|---|
| 소폭 변동 | 3분 | 시장이 멈춰 있지 않다는 리듬 제공 |
| 거래 영향 | 즉시 | 플레이어 행동이 세계에 반영되는 감각 제공 |
| 대형 사건 | 1시간 | 장기 세션의 판도를 바꾸는 외부 변수 제공 |
| 가격 히스토리 | 최근 20개 | 과거 흐름을 읽고 판단하는 정보 플레이 제공 |

## 구현 근거

- `src/marketPrices.js`: 대형 시장 사건과 플레이어 거래 영향 로직 분리
- `src/App.jsx`: 3분/1시간 타이머 운용, 로그/정보 패널 연동
- `src/marketPrices.test.js`: 주기, 즉시 영향, 대형 사건 독립성 검증
- `src/routeSummary.js`: 항로 선택 전 수익/위험/차단 조건 요약

## 개발 AI 사용 내역

| 단계 | AI 보조 내용 | 최종 확인 |
|---|---|---|
| 기획 | 시장 주기, 사건 분리, 제출 문서 구조 정리 | 사람이 스펙 채택 및 수정 |
| 구현 | React 상태 흐름, 시장 로직 분리, 테스트 초안 보조 | 로컬 테스트/빌드로 검증 |
| 비주얼 | 플레이 예시 이미지 방향성, 제출용 화면 선별 | 실제 exe 스크린샷으로 대체 검증 |
| 문서 | 소개서/기술문서/PDF 구성 보조 | 제출 전 버전/파일명/스크린샷 대조 |

## 개선안 및 후속 적용 계획

| 개선 범주 | 현재 반영 | 후속 적용 |
|---|---|---|
| 심사 설득력 | 소개서 첫 장에 매력 포인트와 실제 exe 캡처 증거를 추가 | 제출 직전 데모 영상 썸네일/설명을 같은 메시지로 정렬 |
| AI 시스템 설명 | 3분 소폭 변동, 즉시 거래 영향, 1시간 대형 사건을 분리 설명 | 정보 추천 패널에 “추천 이유” 문장을 붙이는 AI 해석 레이어 추가 |
| UX 정돈 | 핵심 화면 위주로 갤러리를 재구성 | 함대 카드의 좁은 버튼 텍스트를 아이콘/한글 라벨로 정리 |
| Unity 준비 | 현행 React 로직과 테스트 근거를 문서에 남김 | Unity 전환 시 `marketPrices`, `routeSummary`, crew stat 계산을 먼저 C# 포팅 |

## Unity 전환 체크포인트

- 현재는 React/Vite 실행파일 제출이 기준이며, 실제 Unity 프로젝트 파일은 아직 생성하지 않았습니다.
- Unity 전환은 새 프로젝트 생성, 데이터 모델 포팅, 시장/항로/승무원 로직 단위 테스트, UI 재구성 순서가 적합합니다.
- NAN 제출 자료에는 “현재 playable build는 React/Electron, Unity는 후속 이식 계획”으로 명확히 적는 것이 안전합니다.

## 권리 및 라이선스 메모

- 게임명, 코드, 기획, 제출 문서는 프로젝트 고유 창작물입니다.
- React, Vite, Tailwind 등 오픈소스 의존성은 각 라이선스 범위에서 사용합니다.
- 제출용 화면 자료는 `Pioneer_v1.8.1_portable.exe` 실제 실행 화면을 직접 캡처했습니다.
- AI 생성/보조 산출물은 개발자가 검토·수정·채택한 내용만 반영했습니다.
