# Pioneer — NAN 2026 게임 소개서

**장르:** 항해 무역 / 함대 경영 / 캐주얼 전략 시뮬레이션
**플랫폼:** React + Vite 웹 게임 | Electron portable 빌드
**버전:** v1.7.0 | **제출일:** 2026-08-03

---

## 한 줄 소개

> 9개 항구, 10종 상품, 끊임없이 움직이는 시세 —
> Pioneer는 "지금 팔아야 하는가, 더 가야 하는가"를 30초마다 묻는 항해 무역 시뮬레이션입니다.

---

## 왜 Pioneer인가

대부분의 무역 게임은 플레이어가 최적 루트를 한 번 찾으면 반복할 수 있습니다.
Pioneer는 그것을 불가능하게 만듭니다.

시장이 살아 있기 때문입니다 — 3분마다 가격이 흔들리고, 1시간마다 무역풍·봉쇄·흉작이
항구 네트워크를 뒤흔듭니다. 어제의 정답이 오늘의 함정이 됩니다.

---

## 핵심 플레이 루프

```
항구 도착 → 시세·항로 분석 → 목적지·화물 결정 → 출항
  → 항해 이벤트 대응 → 도착 후 거래·성장 → 다시 항구 도착
```

루프 한 사이클 **3~10분** — 짧은 판단이 누적되어 선단 성장으로 이어집니다.

| 단계 | 플레이어 결정 | 게임 피드백 |
|------|-------------|-----------|
| 시세 분석 | "리스본 향신료가 지금 고점이다. 팔까?" | 20턴 가격 히스토리 그래프, 예상 판매 이익 |
| 항로 결정 | "알렉산드리아 — 위험하지만 수익이 크다" | Route Summary: 예상 수익·이동일·위험 등급·대안 항구 |
| 출항 | 목적지 확정 | 날씨·해적·조우 이벤트, 차항 시세 알림 |
| 도착 | 판매·매입·퀘스트 수행 | 수익 원인·손실 원인·다음 추천 행동 피드백 |

## 주요 시스템

### 동적 시장 엔진

Pioneer 경제의 핵심은 세 레이어가 독립적으로 작동하는 생성형 시장 모델입니다.

| 레이어 | 주기 | 효과 |
|--------|------|------|
| 소형 드리프트 | 3분 | 모든 항구 시세 ±2.5% 무작위 변동 |
| 플레이어 충격 | 실시간 | 대량 매입/매도가 해당 항구 가격에 즉시 반영 (최대 ±18%) |
| 대형 이벤트 | 1시간 | 무역풍·봉쇄·흉작이 2~4개 항구에 16~38% 충격파 생성 |

대량 매도를 반복하면 그 항구의 가격이 스스로 떨어집니다.
분산 거래와 타이밍이 전략이 되는 이유입니다.

### Route Summary (항로 요약)

출항 전 한 화면에서 확인합니다:
예상 순수익 | 이동 소요일 | 위험 등급 | 위협 원인 | 대안 항구 비교

결정에 필요한 정보를 이동 없이 모두 보여줍니다.

### 함대 & 선박 성장

- 11종 선박 (스쿠너 ~ 갈레온) — 화물·속도·내구성 트레이드오프
- 선원 고용·훈련 / 선박 수리·업그레이드 / 지역·항로 해금 구조

### 퀘스트 & 일일 목표

- 납품 퀘스트: 특정 항구에 특정 물자를 기간 내 납품
- 일일 목표: 매일 갱신되는 단기 과제로 짧은 세션 완결감 제공
