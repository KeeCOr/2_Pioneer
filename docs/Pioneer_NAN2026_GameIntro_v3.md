# Pioneer NAN 2026 게임 소개서
**장르:** 대항해 무역 / 함대 경영 / 캐주얼 전략 시뮬레이션  
**플랫폼:** React + Vite 웹 게임, Electron portable 실행파일  
**버전:** v1.8.1 | **작성일:** 2026-08-08 | **실행파일:** `Pioneer_v1.8.1_portable.exe`

---

## 한 줄 소개

Pioneer는 29개 항구의 시세를 읽고, 배와 승무원을 키우며, 3분마다 흔들리는 시장과 1시간마다 터지는 대형 사건 사이에서 항로를 결정하는 대항해 무역 시뮬레이션입니다.

## 제출 매력 포인트

| 매력 | 플레이에서 보이는 장면 | 심사 관점 |
|---|---|---|
| 살아 있는 시장 | 거래소, 시세 타이머, 즉시 거래 피드백 | 반복 플레이마다 가격 기억이 달라지는 전략성 |
| 한 화면 의사결정 | 세계 지도, HUD, 함대 카드, 시장 버튼 | 클릭 수를 줄인 캐주얼 접근성 |
| 성장의 손맛 | 함대, 승무원, 일일 목표, 퀘스트 | 짧은 세션 후에도 다음 목표가 남는 구조 |
| AI 활용 명확성 | 가격 생성/시장 사건/개발 보조 문서화 | 공모전 주제인 AI 활용 근거 제시 |

## 개선안 반영 요약

실행파일 캡처를 검토하며 제출 자료의 설득력이 약해질 수 있는 지점을 다음처럼 보강했습니다.

| 발견한 약점 | 반영한 개선 | 기대 효과 |
|---|---|---|
| 소개 첫 장에서 게임의 재미가 기능 목록처럼 보일 수 있음 | “살아 있는 시장”, “한 화면 의사결정”, “성장의 손맛”을 매력 포인트 표로 전면 배치 | 심사자가 1분 안에 게임의 차별점을 파악 |
| 실제 인게임 증거가 적음 | 실행파일 기준 12장 스크린샷 갤러리 추가 | 구현 완료도와 플레이 흐름을 시각적으로 증명 |
| AI 활용이 개발 보조처럼만 보일 위험 | 시장 생성 모델, 거래 영향, 대형 사건 분리를 기술문서와 소개서 양쪽에 명시 | 공모전 주제인 AI 활용성을 게임 시스템 안에서 설명 |
| Unity 전환 준비가 제출 본문과 분리됨 | 후속 개선 로드맵에 Unity 이식 준비 항목을 명시 | 현재 제출물과 다음 제작 단계가 이어져 보임 |

## 핵심 루프

```text
항구 시세 확인 -> 화물 매입/판매 -> 목적지와 항로 선택 -> 항해 이벤트 관찰
-> 도착 후 거래 -> 선박/승무원 성장 -> 다시 시세 확인
```

## 시장 물가 시스템

- 3분마다 모든 항구/상품의 가격이 소폭 변동합니다.
- 1시간마다 외부 충격인 대형 시장 사건이 발생해 2~4개 항구 가격이 크게 출렁입니다.
- 플레이어의 매입/판매 영향은 거래 즉시 반영되며, 3분 소폭 변동 흐름에만 누적됩니다.
- 대형 시장 사건은 플레이어 거래와 분리된 외부 변수로 처리해 “내가 만든 가격 변화”와 “세계가 흔드는 가격 변화”가 구분됩니다.

## 제출 전 후속 개선 로드맵

| 우선순위 | 개선안 | 제출 자료 반영 방식 |
|---:|---|---|
| P1 | 우측 함대 상세 카드의 영문 버튼 줄바꿈을 한글/아이콘 중심으로 정리 | 스크린샷에서는 주요 흐름 중심으로 선별, 개발 TODO로 별도 관리 |
| P1 | 시장 정보 패널에서 “왜 이 항구가 유리한가”를 한 문장 추천으로 강조 | AI 기술문서에 향후 정보 추천 모델 확장 항목으로 반영 |
| P2 | Unity 이식 시 데이터 모델을 먼저 고정하고 UI는 현재 웹 UX를 기준으로 재구성 | Unity 준비 계획과 현행 React 검증 상태를 분리 표기 |
| P2 | 데모 영상은 거래 즉시 반영, 3분 시세, 1시간 사건 타이머가 보이도록 재촬영 | 현재 문서에는 실제 exe 스크린샷으로 선반영 |
